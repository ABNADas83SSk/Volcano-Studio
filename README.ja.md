# Volcano Studio

**差次的発現・存在量解析の結果を可視化し、探索的に解析するブラウザベースのインタラクティブVolcano plot作成ツール。**

Version 1.2 · [English](README.md) / 日本語

## 概要

Volcano Studioは、差次解析の結果を可視化し、候補分子の選定や論文・学会発表用の図の作成を効率化する研究用ソフトウェアです。Excel風の編集可能なデータシートとインタラクティブなVolcano plotを連動させ、プログラミングを必要とせずにデータの探索、統計的閾値の設定、図のカスタマイズを行えます。

トランスクリプトーム、定量プロテオーム、メタボローム、近接標識プロテオームなど、Fold changeとp-valueを用いる幅広い研究に適用できます。シロイヌナズナのAGIコード、遺伝子名、タンパク質アクセッション番号、代謝物IDなど任意の識別子を使用できます。遺伝子アノテーションの自動取得は行わず、入力されたIDを表示します。

## 使用方法

`index.html` をブラウザで開くか、公開後のGitHub Pagesにアクセスしてください。`ja.html` は日本語で起動します。画面の言語選択から日英を切り替えられます。インストールやアカウント登録は不要です。Demoボタンで架空のサンプルデータを読み込めます（実測値ではありません）。

## 入力データ

以下の順番で3列を入力します。

| ID | Fold change (Sample 1 / Sample 2) | p-value |
| --- | ---: | ---: |
| AT1G30440.1 | 2.0 | 0.001 |
| AT2G40980.1 | -1.5 | 0.01 |
| AT3G23160.1 | 0.2 | 0.50 |

上記はlog2 FCを用いた説明用の架空データです。Excelから直接貼り付けるか、XLSX、CSV、TSV、TXTファイルを読み込みます。XLSXでは最初のワークシートが使用されます。FC入力モードは実数比またはlog2値から選択してください。実数比は正の値のみ、log2値は負、ゼロ、正の値を受け付けます。モード変更は入力値の再解釈であり、保存された数値の変換ではありません。

入力するp-valueは、適切な上流解析で得た**未補正のp-value**を使用してください。BH補正済みの値を再度BH補正しないでください。各行は1つの仮説として扱い、重複IDは統合しません。IDや数値が欠損した行、無効なFC、0〜1の範囲外のp-valueは計算・作画から除外されます。

## 主な機能

- Excel風のセル編集、一括貼り付け、行追加・削除、ファイル読込。確認付きの全データクリア、最大80履歴のUndo/Redo（グラフ寸法は履歴対象外）。
- ID、FC、p-value、BH補正p-value、有意判定の昇順・降順ソート。有意・上昇・低下・選択行のフィルタリングおよびID検索。
- 未補正またはBH補正p-valueによる判定、Y軸の選択、p-value閾値、絶対log2 FC閾値、探索的S0曲線の設定。
- マウスオーバーで値を確認、クリックで選択、右クリックメニューでラベル・選択を切り替え。ラベルをドラッグして移動し、選択点や判定グループの色・形・サイズを一括変更。
- グラフ右下のドラッグまたは幅・高さの数値入力による寸法調整、タイトル、ラベル文字サイズの設定。
- シートのXLSX、CSV、タブ区切りTXT出力。表示順で出力する場合は「表示行のみ」を選択（全行出力は内部の行順）。グラフのSVG、PDF、PNG出力（PNGは1〜4倍）。
- データ、点の外観、ラベル位置、主要な作画設定をJSONプロジェクトとして保存・復元。再現性確保のため、元の解析結果も保存してください。

## 統計的背景と計算方法

### Volcano plotの座標

実数比FC = Sample 1 / Sample 2の場合、横軸は x = log2(FC) です。log2 FCが入力された場合はその値を直接使用します。FC = 2、0.5、1はそれぞれx = 1、-1、0に対応します。縦軸は y = -log10(u) であり、uは未補正p-valueまたはBH補正p-valueです。正のxはSample 1における相対的な存在量の増加を意味し、生物学的活性化を直接示すものではありません。

対数変換ではゼロを含む10^-300未満の値を10^-300に置き換えます。これは作画および判定計算に用いる数値処理であり、BH補正自体には元の数値を使用します。p-valueがゼロと報告された場合は丸めや数値アンダーフローの可能性を確認してください。

### Benjamini–Hochberg法による多重検定補正

m個の有効な仮説の未補正p-valueを昇順に並べ、順位iの補正p-valueを以下の式で求めます [1]。

$$q_{(i)} = \min\left(1,\min_{j\ge i}\frac{m}{j}p_{(j)}\right).$$

算出した値を元の行に対応付けます。表示上のソートやフィルタリングにかかわらず、全有効入力行を補正対象とします。FDR列はBH補正p-valueであり、個々の仮説が偽陽性である確率やStoreyのq-valueではありません。

妥当な帰無仮説下のp-valueと、独立性または適切な正の依存性（PRDS）などの条件下で、BH法は棄却集合における偽発見割合の期待値を制御します [1,2]。FDR 5%は、得られた個別の候補リストのちょうど5%が偽陽性であることを保証しません。任意の依存構造ではこの保証はありません。事前に有意な分子だけを抽出してから補正するのではなく、意図した検定ファミリー全体を入力してください。

### 有意判定と効果量フィルタリング

S0 = 0では、u <= alpha かつ |x| >= c を満たす行を有意としてマークします。uは選択されたp-value指標、alphaはその閾値、cは絶対log2 FCの閾値です。初期設定はBH補正p-value、alpha = 0.05、c = 1（2倍以上の増加または減少）です。

本ツールの「有意」は現在の選択基準を満たすという意味です。未補正p-valueを使う場合、その判定に多重検定補正はありません。BH補正後に効果量で絞り込んだ部分集合については、元のBH法のFDR上限が自動的に保証されるわけではありません。また、観測FCの閾値は真の効果量がその値を超えることの検定ではありません。最小効果量に関する厳密な推論にはTREATなどの上流解析手法を使用してください [4]。

### 探索的S0曲線

現行版のS0は独自の効果量依存的な選択曲線を定義するパラメータであり、統計検定ではありません。S0 > 0、|x| > cのとき、以下を選択条件とします。

$$-\log_{10}(u) \ge -\log_{10}(\alpha)+\frac{S_0}{|x|-c}.$$

これは u <= alpha × 10^(-S0/(|x|-c)) と等価です。通常の設定ではS0 > 0のとき|x| = c以下の点は除外されます。実装では分母に小さな正の下限を設けています。S0を大きくすると、特にFC閾値に近い点への選択条件が厳しくなります。S0 = 0で通常の矩形の選択条件に戻ります。

**この曲線はSAMの統計量やPerseusの permutation-based FDRとは異なります** [3,5]。SAMでは反復測定から推定した変動と安定化定数を用いた修正統計量（例：d_i = effect_i / (s_i + s0)）および置換に基づく推論を使用します。本ツールは反復測定値や分散推定値を持たず、置換検定を行いません。S0には校正された統計的誤り率としての意味はなく、選択集合のFDRがalpha以下であることを保証しません。論文ではSAM/PerseusのFDR閾値ではなく、探索的曲線パラメータとして記載してください。

### 閾値線の描画

垂直線は±cを示します。判定指標と縦軸の指標が一致する場合には水平閾値線またはS0曲線を表示します。指標が異なりS0 = 0の場合は、算出可能な場合にデータ依存的な対応水平閾値を表示します。指標が異なりS0 > 0の場合、対応する曲線は描画しません。解釈の明確さのため、特にS0使用時は判定指標と縦軸指標を一致させてください。点の色などは手動変更可能なので、判定状態はシートで確認してください。

## 科学的妥当性と限界

対数変換とBH補正は確立された数学的手法です。ただし、計算方法が妥当であることは、入力データの統計的妥当性や追加の候補選択条件の妥当性を保証するものではありません。

Volcano Studioは差次解析結果の可視化と後処理のためのソフトウェアです。生データからの正規化、欠損値補完、バッチ効果補正、分散推定、統計モデルの当てはめ、未補正p-value計算、置換検定、生物学的意義の判定は行いません。適切な生物学的反復と上流解析を用い、正規化方法、検定法、検定ファミリー、欠損値の処理、FCの定義を記録してください。小さなp-valueは必ずしも生物学的重要性を意味しません。研究・探索用途を想定し、臨床診断には使用しないでください。

### 検証状況

現行コードは上記の順位に基づくBHアルゴリズムを実装しています。検証用の入力p-value [0.001, 0.01, 0.03, 0.04, 0.20] に対する理論上のBH補正値は [0.005, 0.025, 0.05, 0.05, 0.20] です。正式公開前にRの `p.adjust(p, method = "BH")` と実際の出力を比較してください。同順位、ゼロ、無効行、フィルタリング前後の補正値、言語切り替え、Excel貼り付け、画像出力についてもテストが必要です。v1.2について全ブラウザ機能の回帰テストや独立した統計検証が完了しているわけではありません。

使用バージョン、比較方向、FC入力形式、判定指標、縦軸指標、alpha、c、S0を記録し、全入力データとプロジェクトJSONを保存してください。論文ではBH補正と追加の探索的フィルタリングを区別してください。

> Volcano plots were generated using Volcano Studio v1.2. Fold changes were expressed on a log2 scale, and p-values from the upstream statistical analysis were adjusted using the Benjamini–Hochberg method across all valid tested features. Features with BH-adjusted p-values ≤ 0.05 and absolute log2 fold changes ≥ 1 were highlighted. No S0-dependent exploratory filtering was applied.

## プライバシーと依存ライブラリ

データ処理と作画はブラウザ内で行われ、データ送信用バックエンドは実装していません。XLSX入出力とPDF出力はjsDelivrからバージョン固定の外部JavaScriptライブラリ（SheetJS xlsx 0.18.5、jsPDF 2.5.2、svg2pdf.js 2.2.4）を必要時に読み込むため、インターネット接続が必要な場合があります。外部スクリプトはページ内で実行されるため、完全オフライン動作や独立したセキュリティ監査済みとはいえません。機密性の高い未発表データには、監査したライブラリを同梱する構成を検討してください。公開後の不具合報告・機能要望はGitHub Issuesへお願いします。
